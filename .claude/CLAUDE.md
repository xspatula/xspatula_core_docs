# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository. This repo is the new documentation for the sibling repo that used to be under the path `setup_core_db`, but I changed the path to `xspatula_core` (to reflect the more advanced code repos `xspatula_lucas` and `xspatula_ai4sh` and their documentation paths `xspatula_core_docs` and `xspatula_ai4sh_docs`). The initial building of this repo is in the file `.claude/CLAUDE_version1_20260902.md`, the second in `.claude/CLAUDE_version2_20260907.md`

## Project Purpose

`xspatula_core_docs` is a documentation site written in Markdown using the Jekyll theme Minimal
Mistakes (https://mmistakes.github.io/minimal-mistakes/) for the database-integrated Xspatula
framework project written in Python in the sibling repo `xspatula_core`. `xspatula_core` is is the core setup, further developed to full xspatula framework projects in the sibling projects `xspatula_ai4sh` (documented in the sibling repo
`xspatula_ai4sh_docs`) and `xspatula_lucas` (documented in the sibling repo
`xspatula_lucas_docs`).
